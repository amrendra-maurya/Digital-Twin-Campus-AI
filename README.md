# CampusVerse - Interactive Digital Twin Campus

A modern, professional digital twin visualization platform for college campuses with AI-powered insights.

## PHASE 1: Initial Setup

This is the foundational React + Vite application with a professional dark dashboard UI.

### Features Implemented
- ✅ React + Vite setup
- ✅ Professional dark modern UI
- ✅ Navigation system
- ✅ Statistics cards (Demo Data)
- ✅ Campus preview placeholder
- ✅ Campus status panel
- ✅ Responsive design
- ✅ Demo mode badge

### Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open browser
http://localhost:5173
```

### Technology Stack
- React 18.2.0
- Vite 5.0.8
- Recharts (for future analytics)
- Lucide React (for icons)
